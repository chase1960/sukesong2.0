# 仓库域开发边界

仅负责单仓 SKU 数量和不可变库存流水。所有写入通过注册 Action，跨域调用仅经 `shangshu_core.public_api`；不得导入 core、orders 或 finance 私有模块，不读写其他领域 DocType。

- 余额与流水同事务，SKU 行锁防超卖；来源键幂等且校验请求内容，冲销追加反向流水，禁止改写历史。
- 只提供领域贡献、数据集、动作和原生通用流程入口，不复制产品壳或公共 CRUD。
- 权限：Warehouse Manager 管理库存；业务申请审批与订单规则留订单域。
- 当前范围单仓、整件数量，不做预留、批次、成本核算、调拨、多仓及采购定价。
- 测试使用独立回归站，禁止 ACCEPTANCE_ONLY；未安装时不出现仓库导航。
