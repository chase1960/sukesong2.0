# 订单域开发边界

仅负责单商品订单申请与仓管办理。库存事实属于 warehouse，拨款申请与流水属于 finance；跨域只调用 `shangshu_core.public_api` 的注册 Action / Service / 对象读取，不导入其他域实现、不直写其他域表。

- 普通员工仅自己的申请；仓管仅库存分支待办、已退回与已出库单。确认出库仍由仓库域复核余额，订单与库存同事务。
- 外采仅保存财务申请引用，最新拨款结果从财务公共对象读取，禁止复制财务状态。财务退回后的重提沿财务原动作。
- 页面复用通用数据表、详情、动作表单和流程入口；不增加专用 BFF、产品壳或通用框架。
- 当前单仓、单 SKU、整件数量、整笔拨款；不包含定价、报价、物流、分批、税务和会计核算。
- 只在独立回归站测试；验收站不得追加夹具。
